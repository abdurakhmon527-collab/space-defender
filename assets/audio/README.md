Optional audio files. Expected filenames:

- `shoot.wav`
- `explosion.wav`
- `damage.wav`
- `powerup.wav`
- `menu.wav`
- `background.ogg` (looping background music)

Use audio that you created or that is licensed for redistribution. Every file is optional. Missing or unreadable files are skipped, and the game remains playable without an audio device.

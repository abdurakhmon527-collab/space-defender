# Assets

The core game is drawn procedurally with SFML shapes. No third-party image or sound files are required to play.

Optional resources can be added as follows:
- `fonts/Orbitron-Regular.ttf` — optional font. Use a font whose licence permits redistribution.
- `audio/shoot.wav`
- `audio/explosion.wav`
- `audio/damage.wav`
- `audio/powerup.wav`
- `audio/menu.wav`
- `audio/background.ogg` — optional looping background music

Missing optional resources are handled safely. The game will continue without them.
